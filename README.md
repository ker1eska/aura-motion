# AURA // Motion FX Studio (After Effects iOS)

Мобильная студия моушн-дизайна и видеомонтажа уровня After Effects / Alight Motion на Python & WebGL с конвертацией в `.ipa` для установки через 3uTools.

---

## ⚡ Особенности и возможности

1. **GPU Шейдеры эффектов (GLSL)**:
   * **Optic Deep Glow**: мягкое физически корректное свечение с регулировкой радиуса, порога яркости и интенсивности.
   * **RGB Split & Chromatic Aberration**: кинематографичный раскол цветовых каналов с вектором направления.
   * **Cyber Glitch & CRT Scanlines**: горизонтальный сдвиг строк, цифровой шум и телевизионная развертка.
   * **Dynamic Twitch / Shake**: процедурная тряска камеры на гармонических частотах.

2. **Кинетическая типографика (Текстовые анимации AE)**:
   * **Stagger Pop**: буквы вылетают по очереди с задержкой и физическим отскоком (Overshoot curve).
   * **Kinetic Wave**: непрерывная плавная волна по буквам текста.
   * **Neon Typewriter**: появление букв с неоновым световым курсором.
   * **Glitch Scatter**: цифровая сборка букв из хаотичного шума.
   * **Deep Space Zoom**: кинематографичный наплыв из центра с экспоненциальным затуханием.

3. **Кривые скорости (AE Graph Editor)**:
   * Расчет кубических кривых Безье (Cubic-Bezier) методом Ньютона-Рафсона в реальном времени.
   * Пресеты: *Easy Ease (F9)*, *Overshoot (Spring)*, *Physical Bounce*, *Expo Out*, *Linear*.

4. **Многодорожечный таймлайн (Multi-Track Timeline)**:
   * Слой текста, сплошного цвета, медиа и Adjustment Layers.
   * Ромбики ключевых кадров (`◆`), обрезка границ, зум таймлайна, таймкод `00:00:00:00`.

## 🚀 1. Как запустить и протестировать на ПК прямо сейчас

В терминале перейди в папку проекта и запусти:

```bash
python main.py
```

* Если установлен `pywebview` — откроется отдельное темное окно приложения.
* Если нет — приложение автоматически откроется в браузере по адресу `http://127.0.0.1:8080/`.

## 📱 2. Как собрать `.ipa` и установить на iPhone через 3uTools

Файл `AuraMotion.ipa` уже сгенерирован в корне проекта. Если захочешь пересобрать после правок кода:

```bash
python ios/build_ipa.py
```

### Пошаговая установка через 3uTools (без джейлбрейка):

1. **Подключи iPhone** к компьютеру через USB-кабель.
2. Открой **3uTools** на Windows (убедись, что телефон определился и на экране нажато «Доверять этому компьютеру»).
3. В верхнем меню 3uTools перейди во вкладку **Toolbox** (Инструменты).
4. Найди и нажми утилиту **IPA Signature** (Подпись IPA).
5. Нажми кнопку **Add IPA** и выбери сгенерированный файл:
   `c:\Users\kiril\Desktop\for iphone\AuraMotion.ipa`
6. Отметь галочкой добавленный файл и выбери пункт **Sign with Apple ID** (Подписать с помощью Apple ID).
7. Нажми **Add Apple ID** и введи свой логин/пароль Apple ID (это стандартная бесплатная подпись разработчика от Apple).
8. Нажми кнопку **Start Signing** (Начать подпись). 3uTools подпишет приложение твоим личным сертификатом.
9. После завершения нажми **Install** (Установить).
10. **Первый запуск на iPhone**:
    * Перейди в: **Настройки** $\to$ **Основные** $\to$ **VPN и управление устройством** (или *Профиль разработчика*).
    * Нажми на свой Apple ID и выбери **«Доверять»**.
    * Запускай AURA Motion прямо с домашнего экрана!
